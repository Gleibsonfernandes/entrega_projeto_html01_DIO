Bem-vindo ao Mundo do HTML

HTML, ou HTML, é a linguagem padrão usada para criar páginas web. Ele estrutura o conteúdo na web e é essencial para construir sites.

O que é HTML?

HTML é uma linguagem de marcação que utiliza tags para definir elementos dentro de um documento. Esses elementos são os blocos de construção de qualquer página web.

Estrutura Básica de um Documento HTML

Um documento HTML geralmente começa com uma declaração DOCTYPE seguida pelo elemento <html>. Dentro dele, você encontrará as seções <head> e <body>.

  1. <!DOCTYPE>: Declara o tipo de documento.
  2. <html>: Envolve todo o conteúdo HTML.
  3. <head>: Contém metadados, como o título e o conjunto de caracteres.
  4. <body>: Contém o conteúdo visível na página web.

Tags Comumente Utilizadas

  • <h1> - <h6>: Tags de cabeçalho para diferentes níveis de títulos.
  • <p>: Tag de parágrafo.
  • <a>: Tag âncora para links.
  • <ul> e <ol>: Listas não ordenadas e ordenadas.
  • <blockquote>: Para citar um bloco de texto.
Tags Mais Novas e Menos Conhecidas

O HTML continua evoluindo, introduzindo novos elementos. Aqui estão alguns:

  • <abbr>: Para abreviações (ex.: WWW).
  • <del>: Indica texto deletado (Desatualizado).
  • <sub> e <sup>: Subscrito (H2O) e sobrescrito (x2).
  • <small>: Exibe texto menor (Nota: Texto pequeno aqui.).
  • <font>: Especifica tamanho e cor da fonte (Obsoleto).
